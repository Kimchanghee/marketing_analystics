# 2025-12-23 업데이트 내역

## 개요
보안 취약점 수정 및 인증 시스템 강화

---

## Critical 보안 수정

### 1. OAuth 검증 우회 취약점 수정
- **문제**: `POST /login/social` 및 `POST /social/link` 엔드포인트가 `provider_user_id`만으로 로그인/연동을 허용하여 계정 탈취 가능
- **수정 내용**:
  - `POST /login/social` 엔드포인트 완전 삭제 (사용처 없음)
  - `POST /social/link` 엔드포인트 삭제
  - OAuth 콜백(`/oauth/{provider}/callback`)에 `link` 액션 추가하여 안전한 소셜 계정 연동 구현
  - `profile.html`에서 OAuth 버튼으로 변경 (직접 provider_user_id 입력 폼 제거)
- **관련 파일**:
  - `app/routers/auth.py` (라인 219-255, 369-402)
  - `ui/templates/profile.html` (라인 43-49)
  - `ui/pages/dashboard/profile.html` (라인 43-49)

### 2. 이메일 인증 우회 수정
- **문제**: `POST /signup`에서 이메일 인증코드 검증 없이 `is_email_verified=True`로 저장
- **수정 내용**:
  - `verification_code` 파라미터 추가 (필수)
  - `email_verification_service.verify_code()` 검증 로직 추가
  - `signup.html`에 인증코드 입력 필드 및 요청 버튼 추가
  - JavaScript로 인증코드 요청 기능 구현
- **관련 파일**:
  - `app/routers/auth.py` (라인 620-651)
  - `ui/templates/signup.html` (라인 93-102, 579-607)
  - `ui/pages/auth/signup.html` (동일)

### 3. 하드코딩된 테스트 이메일 제거
- **문제**: `admin.py`에 개인 이메일 주소 하드코딩
- **수정 내용**: `TEST_EMAIL_RECIPIENT` 변수 삭제
- **관련 파일**: `app/routers/admin.py` (라인 35)

### 4. `require_roles()` 함수 호출 오류 수정
- **문제**: 5개 엔드포인트에서 리스트 문법 `require_roles([...])` 사용 (varargs 함수인데 리스트 전달)
- **수정 내용**: 모든 호출을 `require_roles(UserRole.X, UserRole.Y)` 형태로 수정
- **관련 파일**: `app/routers/admin.py` (라인 909, 940, 1035, 1104, 1198, 1297)

## High 보안 수정

### 5. 로그인 브루트포스 방지
- **문제**: 로그인 시도 제한 없이 무제한 시도 가능
- **수정 내용**:
  - `LoginThrottleService` 신규 서비스 구현
  - 5회 실패 시 15분 잠금
  - IP + 이메일 조합으로 추적
  - 잠금 시 남은 시간 표시
  - 성공 시 기록 초기화
- **관련 파일**:
  - `app/services/login_throttle.py` (신규)
  - `app/routers/auth.py` (라인 483-557, 604-605)

### 6. OAuth Open Redirect 취약점 수정
- **문제**: OAuth 콜백에서 `next_url` 검증 없이 외부 도메인 리다이렉트 가능
- **수정 내용**:
  - `_is_safe_redirect_url()` 검증 함수 추가
  - 상대 경로(`/`로 시작)만 허용
  - 프로토콜/도메인 포함 URL 차단
- **관련 파일**: `app/routers/auth.py` (라인 471-498, 422)

## Medium 보안 수정

### 7. 이메일 인증코드 암호학적 난수 생성
- **문제**: `random.choices()` 사용 (암호학적으로 안전하지 않음)
- **수정 내용**: `secrets.randbelow()` 사용으로 변경
- **관련 파일**: `app/services/email_verification.py` (라인 7, 28-31)

### 8. 프로덕션 에러 메시지 정보 노출 방지
- **문제**: 에러 발생 시 `str(exc)` 반환으로 내부 정보 노출
- **수정 내용**:
  - 프로덕션: 일반적인 에러 메시지만 반환
  - 개발 환경: 디버깅용 상세 정보 유지
- **관련 파일**: `app/main.py` (라인 71-96)

### 9. 로컬 개발 환경 HTTPS 강제 문제 수정
- **문제**: `build_asset_url()`에서 무조건 HTTPS 변환
- **수정 내용**: `is_production` 설정에 따라 분기 처리
- **관련 파일**: `app/main.py` (라인 41-59)
